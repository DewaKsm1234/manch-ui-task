## Performance Hub (Vite + React + Tailwind CSS v4)

Employee Performance Management dashboard with role-based routing for:
- **Admin**
- **Managers**
- **Employees**

---

## Setup (Install)

### Prerequisites
- **Node.js**: 18+ recommended
- **npm**: comes with Node

### Install dependencies

```bash
npm install
```

---

## Run the project

### Development (hot reload)

```bash
npm run dev
```
